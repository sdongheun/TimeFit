# DEC-KAKAO-ROUTE-START-02 — 코스 이동 의사와 외부 열기 결과 분리

## 상태와 관계
2026-09-09 DOCS-KAKAO-ROUTE-START-02 완료. COURSE-13/15, UXV-43/51, DEC-KAKAO-ROUTE-01 및 Live Activity 시작 조건의 보완·충돌 교체다. 사용자가 클릭 기준을 확정하고 구현 후 직전 확인 목록 1번 전체에 ‘1번 확인 완료’라고 보고했다. 구현·자동 회귀·사용자 수동 확인을 수락한다. 구체적인 기기별 결과·테스트 빌드 식별값·캡처는 미제공이며 추정하지 않는다.

## 교체 이력
- 이전: 외부 handoff 수락/background 관찰 후 이동 확정. WEB-RETURN-01은 정상 닫기의 거짓 오류만 제거.
- 관찰: 앱 미설치 사용자가 설치없이 웹 지도를 이용해도 복귀 시 도착 버튼으로 진행하지 못함.
- 교체: 코스 길찾기 클릭을 명시 이동 의사로 공유 저장 → Activity 시도 → 외부 열기. 웹 팝업 취소·닫기·복귀에도 유지.
- 이유: 외부 웹 내부 클릭 추적/별도 앱 복귀 확인 없이 설치 여부 차이 해소.
- 현행: 클릭 기준. 철회: 코스 시작의 외부 성공 선행 조건, 별도 ‘이동 시작하기’ 제안. 보존: 정상 종료 무오류, 실제 실패 재시도, 외부 결과 enum 및 URL 계약.

## 기대 결과·예외
1. 유효한 현재 구간만 클릭 시 이동 상태를 저장한다. 첫/다음 구간은 도착 행동, 최종 구간은 기존 완료 행동을 사용한다.
2. 앱/Live Activity 공유 상태를 유지한다. Activity 권한 거절/시작 실패는 길찾기를 막지 않는다. 공유 저장 실패·다른 run 충돌은 안전하게 차단한다.
3. 모든 외부 열기 시도가 실제 실패한 경우에만 이번 신규 의사를 소유/run/revision/phase/시각/event 경계로 복구한다. 이미 도착·완료·다른 run이면 늦은 결과가 덮어쓰지 않는다.
4. 웹 종료는 성공 증거도 실패 근거도 아니다. 외부 URL 수락과 이동 의사의 의미를 혼동하지 않는다.
5. 재열기/연타는 이동 시각·알림·Activity를 중복 초기화하지 않는다. 재열기 실패는 기존 이동을 보존한다. cold 복원은 자동 외부 재실행을 하지 않는다.
6. native 명시 출발은 실패/재시도에서도 보존한다. 잠금 해제 등 기존 외부 실행 제약을 우회하지 않는다.
7. 클릭을 실제 도착·방문·체류 학습 증거로 사용하지 않는다. 기존 명시 도착·출발, 증거/동의/완료 표본 계약을 유지한다.
8. 주변 둘러보기는 독립 정보 탐색이다. 진행·기록·체류·학습·Activity를 생성하지 않는다.
