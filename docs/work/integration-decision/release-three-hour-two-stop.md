## 이전 방식 → 교체 이유

최대120분 → 사용자가 긴 자투리 시간의 선택 가능 범위 확대를 요청 → 최대180분·최대2곳 → 출시 범위를 과도하게 늘리지 않고 긴 입력을 허용 → 현행 정책, 코드 전환 대기. 과거120분 상한은 구현 완료 후 복원할 정책이 아니라 교체 이력이다. 120분 이하 입력 자체와 기존 fixture는 유효하다.

## 불변 정책

- 체류시간 자동 연장/3곳 자동 조립/호출 예산 확대 없음. 최소 체류·장소별 배정·개인화·운영시간·도착 여유·선택/취소·최적 방문순서 계약 유지.
- 첫 추천과 더보기/2곳 요청의 기존 provider 예산을 유지한다. 더 긴 입력이 결과 다양성 증가를 보장한다고 표현하지 않는다.
- 주변 둘러보기 반경3km와 무시간제 탐색은 무관하다. 문자열 길이120, padding120, timeout12000, 기존 엔진 구간별 분기120은 입력 상한과 동일하지 않다. 숫자 일괄 치환 금지.
- 자정 경계는 날짜를 포함해 계산하고 익일 표시와 운영시간을 검증한다. 23:59 clamp로 180분을 조용히 축소하거나 음수/같은 날 시각으로 바꾸지 않는다. 안전하게 지원할 수 없는 경계가 발견되면 정책을 임의 완화하지 말고 근거/최소 변경을 인계한다.
