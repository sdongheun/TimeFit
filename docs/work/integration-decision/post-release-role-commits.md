# 출시 후 역할별 커밋 인계

2026-09-12. 사용자가 App Store 배포 완료를 보고하고, 유지보수에 앞서 현재 변경을 역할별 커밋으로 보존하도록 요청했다. 스토어 상태를 별도로 조회한 결과나 출시 IPA와 작업트리의 바이너리 동등성 검증은 아니다.

## 1. 변경 파일과 목적

이전 상태는 여러 역할의 출시 준비 변경이 미커밋 상태로 누적되어 있었다. 이를 파일 소유 경계별 커밋으로 보존하여 후속 문서 재구성·테스트 보강·리팩터링의 비교 기준을 만든다. 상태: 현재 작업트리 보존. 기존 구현 내용을 추가 변경하지 않는다.

| 역할 | 커밋 범위와 목적 |
| --- | --- |
| 데이터 | `docs/work/data-curation/`의 사진 이용 근거·출시 자산 감사 인계. 원본/카탈로그 변경 없음 |
| 추천 엔진 | `src/engine/`, 해당 엔진 테스트·인계: 날짜 경계 및 ODsay 신규 호출 제거 |
| DB·개인화 | 계정/가입/게스트 가져오기/코스 저장 repository, 탈퇴 함수·잠금 의존성, 관련 테스트·DB 인계 |
| 외부 API | 코스 경로 어댑터와 API 계약 테스트·API 인계 |
| UIUX | 화면·Live Activity 네이티브 플러그인·아이콘·빌드 설정/스크립트 및 화면 테스트·UI 인계 |
| QA·출시 | 역할 전용 테스트 외 통합/QA 테스트, 공개 사이트와 출시 문서·검증 도구 |
| 통합·결정 | 중앙 정책·색인·테스트 명세·작업 조정·결정 이력 및 이 인계 |

`src/services/releaseIdentitySupabase.ts`는 가입·탈퇴 API 연결과 게스트 가져오기 변경이 함께 있는 파일이다. 이를 임의로 분할하지 않고 DB·개인화 커밋에 귀속한다. `app.json`, 패키지 잠금파일과 빌드 스크립트는 GPS 의존성 제거·출시 UI/네이티브 설정을 함께 보존하기 위해 UIUX 커밋에 귀속한다. 각 중간 커밋의 독립 실행을 보증하지 않으며 검증 기준은 전체 묶음이다.

`output/`의 촬영본·이미지 생성 중간 산출물은 Git에 추가하지 않고 로컬에 보존한다. 실제 앱에서 참조하는 `assets/jjaturi-icon-blue.png`는 포함한다. 비밀키·서명 파일·환경파일은 추가하지 않는다.

## 2. 변경하지 않은 경계

- 수동 위치, 최대 180분/2곳, 계정별 기록 분리와 체류 개인화, 앱/Live Activity 공유 진행 정책 유지.
- 제품 코드 수정·삭제, DB 운영 변경, 공개 사이트 배포, 스토어 변경, 원격 Git push 없음.
- 과거 문서의 준비/보류 상태를 삭제하지 않으며 기능별 문서 재편은 후속 작업으로 분리.

## 3. 실행 검증

- 기존 추적 파일의 `git diff --check`: 통과. 신규 UI 파일을 stage한 뒤 `src/ui/recommendation/ConditionalVisitSection.tsx:16`의 EOF 빈 줄 경고 1건이 추가 확인됐다. 현재 소스 보존을 위해 수정하지 않고 인계한다(실행 오류 아님).
- 신규 출시 문서 `docs/05_release/publish/notice-inquiries.md`의 줄 끝 공백 경고 5건은 Markdown 강제 줄바꿈용 두 칸이다. 문서 표현을 유지한다.
- 커밋 후보 280파일에 비밀키/JWT 패턴 및 로컬 비공개 환경변수 값 일치 검사: 발견 없음. 공급자 전체 보안 감사는 아님.
- `npm run test:typecheck`: 통과.
- `npm test`: 484 통과, 실패 0.
- `npm run test:ui`: 787 통과, 1 건너뜀, 실패 0. 최초 샌드박스 IPC 권한 오류 후 권한 허용 실행으로 검증.
- 새 실기기/Archive 검증은 하지 않았으며 기존 출시 검증을 새로 수행했다고 간주하지 않는다.

## 4. 후속 작업과 주의

다음 작업은 기능별 문서 재정리다. 현행 기준과 철회 이력을 구분하고, 그 뒤 테스트가 없는 동작을 조사·보강한다. 테스트의 통과 개수만으로 미검증 기능이 없다고 판단하지 않는다. 이번 묶음을 특정 출시 바이너리와 동일한 릴리즈 태그로 만들지 않는다. 커밋 해시는 Git 이력과 사용자 인계에 제시한다.
