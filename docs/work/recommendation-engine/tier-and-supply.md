# 추천 tier·공급량 관찰

## 범위

`2-K`, `2-L`과 RD-DIAG 관찰: 가까운 1곳(N1) → 독립 2곳(N2) → 넓은 1곳(W) → 3곳(T) 순서와 실제 추천량 제약을 분리했다.

## 현행 계약

- 대표는 1~2곳을 우선한다. 3곳은 가능하지만 대표를 위해 강제하지 않는다.
- W는 N1 검증 상태와 시간 gate를 지키며, T는 최후순위다.
- 사상→서면 진단에서 후보 공급·화면 누락이 아니라 A8 새 provider attempt 8회 소진이 후속 tier 미시도의 직접 관찰 조건이었다.
- 이 관찰은 12/16이 반드시 더 많은 코스를 만든다는 증거가 아니다. 그래서 B12를 production이 아닌 internal 비교로 한정했다.
