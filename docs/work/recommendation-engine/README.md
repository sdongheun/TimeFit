# 추천 엔진 현재 작업

## 먼저 읽을 파일

1. `AGENTS.md`, `docs/README.md`, `docs/작업조정_보드.md`
2. `docs/03_product/추천로직.md`
3. [B12 internal 검증 묶음](b12-internal-validation.md)

## 현재 상태

`2-M`, `2-N`은 수락됐다. 엔진에 활성 구현 작업은 없다. UIUX가 B12 internal build 조립을 마칠 때까지 엔진 정책·상한을 다시 바꾸지 않는다.

## 이력

과거 세부 기록은 `docs/03_product/추천엔진_작업기록.md`에 보존한다. 현재 작업을 수행하기 위해 해당 문서 전체를 읽지 않는다. 현재 파일이 필요한 anchor만 가리킬 때만 연다.
