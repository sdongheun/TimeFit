# U-NEARBY-SIMPLE-01 — 주변 UI 간소화·독립 길찾기

상태: 2026-09-08 사용자 확정, UIUX 실행 가능. 주변 둘러보기만 먼저 마감한다.

## 목적·교체 이력

기존 상세의 반복 운영시간 경고·장소 확인 링크와 시트 접기/펼치기 텍스트 → 정보가 많고 원하는 이동 행동은 없음 → 안내를 줄이고 선택 장소의 외부 길찾기만 추가 → 약속 시간과 무관한 주변 탐색 역할 명확화 → 구현 전.

기존 `기준 위치에서 가까운 순 · 직선거리` → 사용자가 불필요하다고 지적 → **`가까운 순`** → 현재 기준 위치는 상단에 이미 표시하므로 반복 설명 최소화 → 확정. 거리 계산·정렬은 기존 직선거리 그대로이며 도보거리/이동시간으로 이름을 바꾸거나 환산하지 않는다.

기존 접기/펼치기 텍스트 버튼 → 스와이프 조작과 중복 → 손잡이 드래그+탭+접근성 행동 → 시각 단순화와 조작성 보존 → 확정. 기존 드래그 끊김 수정은 유지한다.

## 읽기·소유 경계

AGENTS.md, docs/README.md, 본 문서, nearby-browse.md의 기존 시트 드래그 수락/표시 계약만 읽는다. NearbyBrowseScreen.tsx, nearbyBrowseModel.ts, 관련 gesture helper/테스트 및 기존 외부 카카오 URL helper를 확인한다.

UIUX src/ui/관련 테스트/본 문서만 수정한다. App/nav 공용 변경은 불가피한 경우만 단일 작성자로 인계한다. 추천 engine·data catalog·API client/서버·DB·체류·알림 계약은 변경하지 않는다. 주변 길찾기는 외부 앱 연결일 뿐 코스 기능이 아니다.

## 구현

1. 시트 목록 부제는 `가까운 순`으로 교체하고 우측 접기/펼치기 텍스트 버튼은 제거한다. `3km 안 장소 N곳` 및 실제 기준 위치 표시는 유지한다. 상세 거리에서도 중복된 시각 설명을 줄일 수 있으나 거리 숫자를 다른 의미로 바꾸지 않는다. 접근성 라벨에는 필요하면 기준 위치와 직선거리 의미를 남긴다.
2. 상세의 `정보 탐색 장소 · 방문 전 운영시간을 확인해 주세요` 반복 문구를 제거한다. 실제 운영시간 데이터는 있으면 유지하고 없으면 허위 ‘영업 중’이나 추정 영업시간을 만들지 않는다. 오류·권한 거절·지도 실패·위치 불명 안내는 필요한 상태에서만 짧게 유지한다.
3. 기존 손잡이 영역에서 스와이프와 탭 전환이 모두 가능하게 한다. VoiceOver label/state/action 제공. 충분한 터치 영역, 드래그 종료를 탭으로 오인해 반대로 전환되는 문제, spring 중 재잡기/탭/치수 변경/취소를 회귀 검증한다. gesture 라이브러리 교체나 손잡이 밖 전체 목록 drag 확장은 하지 않는다. floating 탭바·하단 연결 시트·내용 bottom padding·마지막 행 접근·지도 inset 갱신 시점은 유지한다.
4. 마커/목록 선택 → 기존 상세 시트 → **`카카오맵 길찾기`**를 주요 행동으로 제공한다. 기존 장소 정보 외부 링크는 보조 텍스트 행동으로 두되 같은 크기의 주요 CTA 두 개를 만들지 않는다. 선택 장소의 검증된 목적지 좌표/이름만 외부 URL로 전달한다.
5. 탐색 기준 위치를 사용자 실제 현위치로 오인하지 않는다. 목적지만 전달해 카카오맵에서 현위치/출발지를 정하도록 하는 기존 지원 링크가 있으면 우선 재사용한다. 현위치를 명시 전달해야 하는 방식이면 실제 허용된 위치만 사용하고 없을 때 출발지 선택이 가능한 정상 외부 흐름을 안내한다. 앱/HTTPS fallback 및 목적지 보존은 실제 helper 계약을 확인하며 URL 형식을 추측하지 않는다. 추가 길찾기 API 호출로 경로 계산하지 않는다.
6. **코스용 길찾기 orchestrator를 재사용하지 않는다.** 순수 URL 생성/외부 열기 helper만 재사용할 수 있다. 코스 생성/담기/시작·완료, 활성 코스 단계 변경, 완료/방문 기록, 체류 학습·표본, 알림·Live Activity·outbox·DB 쓰기0을 보장한다. 진행 코스가 있어도 어떤 단계도 바꾸거나 취소하지 않는다.
7. 연타는 외부 실행 중 중복 열기를 막고, 실패 시 현재 상세와 선택 장소를 유지하며 짧은 안내를 표시한다. 외부 복귀 후에도 탐색 위치·목록·선택·기존 진행 코스는 유지한다.
8. 다크/파란색 유지. `docs/03_product/UIUX_공통규칙.md`의 **UX-COLOR-01**을 먼저 읽고 이 화면에 적용한다. 어두운 버튼/보조 링크/활성 행동 텍스트는 흰색 계열, 파란 주요 버튼도 흰색 텍스트로 표시한다. 파란색은 아이콘/선택 표시/배경/테두리로 유지한다. 보조 회색·비활성·오류 등 의미 구분은 보존한다. 이 화면에서 중복 문장/장식 아이콘/중첩 박스를 줄이고 제목·간격·굵기로 구분한다. 모든 버튼 햅틱은 추가하지 않으며 기존 눌림 애니메이션 유지. 색상 규칙은 앱 전체에 확정됐지만 이번 구현은 주변 화면부터 마감하고 타 화면 잔여 적용 목록을 남긴다. 전역 색상 상수의 무차별 치환이나 다른 화면 구조 개편은 하지 않는다.

2026-09-08 보완 이력: 어두운 버튼의 파란 텍스트 → 사용자가 선명도 부족 지적 → 흰색 계열 행동 텍스트와 비텍스트 파란 강조 → 가독성 개선 → 사용자 확정·구현 전. 기존의 ‘전체 디자인은 별도’ 경계가 새 공통 색상 결정을 미확정으로 취급하는 근거가 되어서는 안 된다.
