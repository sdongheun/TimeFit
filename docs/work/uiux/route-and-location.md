# UIUX 경로 설정·장소 선택

## 범위

`U-1-F-R4`~`R8`: 출발/도착 별도 입력을 카카오맵식 단일 경로 설정으로 바꾸고, 현재 위치·검색·지도 핀 선택을 연결한 워크스트림이다.

## 유지 계약

- 검색은 장소명·주소 의도에 맞는 Kakao 단일 provider 결과를 사용하며 명시 선택 전 확정하지 않는다.
- 지도 핀 선택은 사용자 조작 뒤 1회만 주소를 확인하고, GPS가 없으면 안전한 fallback 상태를 보인다.
- 출발지와 도착지 변경은 하나의 화면에서 처리하며, 위치 권한은 명시 행동에서만 요청한다.
