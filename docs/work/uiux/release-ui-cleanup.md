# U-RELEASE-UI-CLEANUP-01 — 시간 설정·추천 화면 정리

상태: UI 구현·자동 검증 완료(2026-09-08), 최소 실기기 확인·통합 수락 대기. 담당: UIUX. 통합 세션이 작성한 실행 명령이며 작업 ID만 전달받아도 본문 전체를 수행한다.

## 최신 결정·교체 이력

- 오늘/내일 선택 → 자유로운 날짜 예약으로 오해 가능 → 시각 휠만 유지하고 자정 경과 때만 ‘다음 날 도착’ 표시 → 현재부터 최대 180분이라는 의미 명확화 → 확정·구현 전.
- 10~18시 ‘운영시간 확인 후 들러볼 곳’ 및 조건부 수동 코스 → 폐기 결정 뒤에도 추천 화면에 잔존 → 추천 진입 제거, 주변 둘러보기의 독립 탐색·길찾기 유지 → 검증 추천과 정보 탐색 분리 → 기존 추천 진입은 철회, 제거 구현 전.
- 추천 헤더의 빈 버튼형 View → 의미 없는 네모 노출 → 투명 정렬 공간 → 제목 정렬만 유지 → 확정·구현 전.

과거 REC-29·UX-22 등의 조건부 추천 노출/수동 포함 지시와 오늘/내일 선택 UI는 이번 사용자 결정으로 해당 범위만 대체한다. 과거 지시를 복원하지 않는다. 내부 날짜 보존 및 운영시간 검증 자체는 철회하지 않는다.

## 읽을 문서

AGENTS.md, docs/README.md, UIUX 공통 규칙·테스트 명세, docs/테스트.md의 관련 ID와 본 명령을 읽는다. 날짜 보존 경계는 course-date-preservation.md의 최종 연결 검증, 시간 입력은 release-three-hour-time-setup.md를 참조한다. 과거 전체 이력을 순회하지 않는다.

## 1. 날짜 선택 단순화

- 시간 설정의 오늘/내일 선택 항목을 제거하고 도착 시각 휠을 유지한다.
- 현재부터 최대 180분 검증과 내부 시작·종료 날짜 보존을 유지한다. 시각이 자정을 넘어 유효 범위에 들어가는 경우만 ‘다음 날 도착’을 보조 표시한다.
- 모든 과거 시각을 무조건 내일로 보정하거나 범위 밖 시간을 허용하지 않는다. 기존 유효성 오류·최소 입력 정책은 유지한다.
- 휠 관성·선택 햅틱·하단 버튼·개발 도구를 유지한다. 개발 버튼을 제외한 기본 화면의 무스크롤 배치를 유지한다.

## 2. 폐기한 조건부 추천 연결 제거

- ResultsScreen의 조건부 영역을 모든 시간대와 정상 결과·빈 결과·후보 소진·더보기·화면 복귀 상태에서 제거한다.
- 해당 영역의 카드·로컬 더보기·사용자 확인 후 수동 코스 계산 진입을 제거한다. 문구만 숨기지 말고 참조 확인 후 화면 전용 상태·타이머·콜백을 정리한다.
- 공유 엔진/API와 장소 원본 데이터는 변경하거나 삭제하지 않는다. 주변 둘러보기의 기존 적격 장소 노출·독립 길찾기를 유지하며 범위를 임의 확대하지 않는다.
- 정상 검증 추천의 ‘다른 장소 더 보기’, 상세 선택·선택 취소·최대 2곳 조립은 유지한다.
- 해당 개발 미리보기 의존성은 확인하고 출시 추천으로 연결되지 않게 정리·기록한다. 다른 개발 도구를 일괄 제거하지 않는다.

## 3. 빈 네모 제거

- 추천 헤더의 제목 정렬용 빈 View에서 버튼 배경·테두리를 제거한다.
- 투명 정렬 공간, 제목 중앙 정렬, 뒤로가기, safe area를 유지한다. 빈 공간은 터치·접근성 버튼 대상이 아니다.

## 검증·수락 조건

수정 전 실패하는 fixture를 추가하고 다음을 검증한다.

1. 일반 시간과 자정 경과에서 날짜 선택 없음, 필요할 때만 다음 날 표시. 180분 허용·181분 거절 및 날짜 보존 회귀.
2. 09:59·10:00·17:59·18:00 모두 조건부 영역·수동 계산 진입 없음. 시간 경과·foreground 복귀에도 재노출 없음.
3. 정상 추천·더보기·선택/취소·주변 독립 길찾기 유지. 헤더 빈 영역은 버튼형 표현과 접근성 동작 없음.
4. npm run test:typecheck, npm run test:ui, npm test, iOS export 실행. 철회한 UI 기대값은 변경 이유를 기록하고 교체하되 날짜·정상 추천 회귀를 삭제/skip하지 않는다.

고정 fixture 우선. 운영 API·DB 변경, 반복 시뮬레이터 조작, migration·개인화 C 재실행은 하지 않는다. 자동 검증과 실제 시각/터치 체감 확인을 구분한다.

## 소유 경계·종료 인수인계

UIUX 소유 코드·화면 테스트만 수정한다. 중앙 기준 문서는 직접 바꾸지 말고 REC-29·UX-22 등 충돌 항목 및 교체 문구를 통합 세션에 인계한다. 역할 밖 수정이 필요하면 범위·계약을 반환한다. 최대 180분·2곳, 날짜 저장, 체류·개인화·알림/Live Activity 정책은 유지한다.

본 문서에 변경 파일과 목적, 변경하지 않은 계약, 실행 테스트·결과, 결정 필요 사항·위험·최소 실기기 확인을 기록한다. 현재 상태를 구현 완료로 미리 표시하지 않는다. 별도 승인 없는 commit/push는 하지 않는다.
