# 실기기 추천 검증 기록

> 목적: 고정 fixture가 아닌 실제 iPhone에서 `CAPTCHA → 익명 session → Route Proxy → Kakao 실제 경로 → 2-J 결과`가 사용자에게 납득 가능한 추천으로 끝나는지 확인한다. 이 문서의 각 **사용자 코멘트** 영역은 사용자가 직접 작성하며, 비밀값·JWT·정확한 GPS·URL query는 적지 않는다.

## 실행 공통 조건

- 테스트 대상: 최신 internal build. `EXPO_PUBLIC_ROUTE_PROXY_ENABLED=true`, internal diagnostics 표시 상태.
- 출발·도착은 GPS가 아닌 앱 검색에서 아래 장소를 **명시 선택**한다. 제안 목록에 같은 이름이 여러 개면 실제로 누른 항목의 표시명만 기록한다.
- 개발 테스트 시각은 `15:00`, 도착 전 남길 시간은 `10분`으로 통일한다. 각 시나리오의 도착 시각만 표에 맞춘다.
- 한 시나리오는 “이 시간에 할 일 찾기”를 **한 번만** 누른다. 같은 입력의 새 추천·재시도·캐시 삭제는 하지 않는다.
- 오류면 화면의 안전 diagnostics enum만 기록하고 다음 시나리오로 넘어간다. `route_proxy_transport_failed`가 다시 나타나면 이후 시나리오를 중단한다.
- 코스가 나오면 장소명, 장소 수, 도보/대중교통 구간, 총 소요·남는 시간, 이해하기 어려운 점만 적는다. 스크린샷은 선택 사항이며 개인 위치가 보이면 가린다.

## 결과 판정

| 판정 | 의미 |
| --- | --- |
| `성공` | 1~3곳 코스 또는 대안 목록이 표시되고, 시간표가 입력 도착 시각과 모순되지 않는다. |
| `정직한 결과 없음` | “경로를 찾지 못했다” 또는 안전한 빈 상태가 입력·시간 조건상 납득 가능하며 diagnostics가 없다. |
| `검증 불가` | `route_proxy_limited`, `route_proxy_rejected`, `route_proxy_store_unavailable` 등 안전 enum이 표시된다. |
| `결함` | `route_proxy_transport_failed`, 앱 멈춤, 잘못된 출발/도착, 시간 초과 코스, 같은 장소 반복, 이해할 수 없는 결과. |

## 시나리오

### RD-01 — 서면의 80분 왕복 여유

| 입력 | 값 |
| --- | --- |
| 출발지 | 서면역 부산1호선 |
| 도착지/복귀 | 출발지로 돌아오기 |
| 테스트 시작 / 도착 | 15:00 / 16:30 |
| 확인 목표 | 대표 1~2곳 코스가 가능한지, 결과가 없더라도 그 이유가 이해되는지 |

**사용자 코멘트:**
- 롯데백화점 부산본점밖에 안뜸. 너무 적은 장소가 뜬다.

**2-L 재검증 코멘트 (2026-08-30, 입력 이탈):**
- 판정: 검증 불가 — 고정 도착 16:30 대신 16:50으로 실행됨
- 대표/대안 코스 수 및 장소명: 대표 1개 `롯데백화점`(1곳), 대안 2개 `포셋 전포`(1곳), `아비베르컴퍼니`(1곳)
- 이동·총 소요·남는 시간 관찰: 대표·대안 모두 도보로 표시됨. `포셋 전포`와 `아비베르컴퍼니`는 각각 도보 12분; 총 소요·남는 시간은 사용자 관찰값 미수집
- 가까운 대안 / 먼 한 곳·3곳 우선 여부: 대표와 두 대안이 모두 가까운 1곳으로 보였으나, 100분 유효 시간 입력이므로 기존 80분 기준선과 비교해 2-L 개선으로 판정하지 않음. 먼 한 곳·3곳이 가까운 대안을 밀어낸 관찰은 없음
- diagnostics 또는 검색·경로 설정 관찰: diagnostics 미표시 보고, 검색·경로 설정 어려움 미보고

**2-L 재검증 교정 실행 (2026-08-30, 사용자 승인 1회):**
- 판정: 개선 관찰 — 고정 입력 `서면역 부산1호선` 복귀, 15:00→16:30, 도착 전 여유 10분을 확인함
- 대표/대안 코스 수 및 장소명: 대표 `롯데백화점 부산본점` 1곳, 대안 `포셋 전포` 1곳·`아비베르컴퍼니` 1곳(총 3개 코스)
- 이동·총 소요·남는 시간 관찰: 대표는 도보 9분 → 활동 30분(15:09~15:39) → 도보 9분, 검증 코스 58분·남는 시간 32분. 대안은 각각 64분·남는 시간 26분, 65분·남는 시간 25분; 대안의 구간 수단 상세는 결과 목록 화면에서 미표시
- 가까운 대안 / 먼 한 곳·3곳 우선 여부: 부산진구의 가까운 1곳 대표와 서로 다른 가까운 1곳 대안 두 개가 표시됨. 이전 롯데백화점 단일 결과보다 가까운 선택지가 늘었고, 먼 한 곳·3곳이 가까운 대안을 밀어낸 관찰은 없음
- diagnostics 또는 검색·경로 설정 관찰: diagnostics 미표시. 결과 화면 캡처로 대표 시간표와 대안 총 소요·남는 시간을 확인함

### RD-02 — 서면의 110분 왕복 여유

| 입력 | 값 |
| --- | --- |
| 출발지 | 서면역 부산1호선 |
| 도착지/복귀 | 출발지로 돌아오기 |
| 테스트 시작 / 도착 | 15:00 / 17:00 |
| 확인 목표 | 긴 시간에서 1~2곳 우선 대표와 대안 목록이 자연스럽게 보이는지 |

**사용자 코멘트:**
- 1번과 같은 거 하나, 부산 동구도서관 91분, 남는시간 19분. 너무 작은 장소가 뜬다.

**2-L 재검증 코멘트 (2026-08-30):**
- 판정: 개선 관찰 — 가까운 1곳 대안은 늘었으나 2곳 코스는 미관찰
- 대표/대안 코스 수 및 장소명: 대표 `롯데백화점 부산본점` 1곳, 대안 `포셋 전포` 1곳·`아비베르컴퍼니` 1곳(총 3개 코스)
- 이동·총 소요·남는 시간 관찰: 대표는 도보 9분 → 활동 30분(15:09~15:39) → 도보 9분, 검증 코스 58분·남는 시간 62분. 대안은 각각 64분·남는 시간 56분, 65분·남는 시간 55분; 대안 구간 수단 상세는 결과 목록 화면에서 미표시
- 가까운 대안 / 먼 한 곳·3곳 우선 여부: 대표와 대안 모두 부산진구의 가까운 1곳 코스로 표시됨. 2곳 코스는 없었으나, 먼 한 곳 또는 3곳이 가까운 대안을 밀어낸 관찰은 없음
- diagnostics 또는 검색·경로 설정 관찰: 입력 `서면역 부산1호선` 복귀, 15:00→17:00, 도착 전 여유 10분을 확인함. diagnostics 미표시, 검색·경로 설정 어려움 미보고

### RD-03 — 사상역에서 서면역으로 이동 전 여유

| 입력 | 값 |
| --- | --- |
| 출발지 | 사상역 |
| 도착지 | 서면역 부산1호선 |
| 테스트 시작 / 도착 | 15:00 / 17:00 |
| 확인 목표 | 다른 생활권 출발에서 대중교통 또는 도보 조합이 시간표에 맞는지 |

**사용자 코멘트:**
- 사상역 2호선, 서면역 2호선으로 함. 부산 수학문화관 코스, 희와제과 코스가 뜸. 너무 적은 장소가 뜬다.

**2-L 재검증 코멘트 (2026-08-30):**
- 판정: 변화 없음 — 시간표는 납득 가능했으나 이전 관찰과 같은 2개 코스여서 가까운 대안 증가를 확정하지 않음
- 대표/대안 코스 수 및 장소명: 대표 `부산 수학문화관` 1곳, 대안 `사상문화원` 1곳(총 2개 코스)
- 이동·총 소요·남는 시간 관찰: 대표는 대중교통 18분 → 활동 30분(15:18~15:48) → 대중교통 7분, 검증 코스 65분·남는 시간 55분. 대안은 95분·남는 시간 25분; 대안 구간 수단 상세는 결과 목록 화면에서 미표시
- 가까운 대안 / 먼 한 곳·3곳 우선 여부: 사상구의 `사상문화원`과 부산진구의 `부산 수학문화관`이 서로 다른 1곳 코스로 표시됨. 3곳 코스가 가까운 대안을 밀어낸 관찰은 없으나, 이전 `부산 수학문화관`·`희와제과` 두 코스 관찰과 비교할 거리/순위 근거가 부족해 개선으로 판정하지 않음
- diagnostics 또는 검색·경로 설정 관찰: 입력 `사상역 2호선` → `서면역 2호선`, 15:00→17:00, 도착 전 여유 10분을 확인함. diagnostics 미표시, 검색·경로 설정 어려움 미보고

## 테스트 뒤 통합·결정에 전달할 내용

각 시나리오마다 아래 다섯 가지만 남긴다.

1. `성공 / 정직한 결과 없음 / 검증 불가 / 결함`
2. 표시된 코스의 장소명과 장소 수, 또는 화면 문구
3. diagnostics enum이 있으면 그 enum 하나
4. 이동·체류·남는 시간 중 납득되지 않는 값
5. 장소 검색·경로 설정에서 선택이 어려웠던 점

모든 시나리오를 완료할 필요는 없다. `route_proxy_transport_failed`, 앱 종료, 잘못된 시간표가 나오면 즉시 멈추고 해당 시나리오의 코멘트만 남긴다.
