# 실시간 공공데이터 로컬 연결 검증 (2026-09-22)

## 범위와 상태

- 대상: 기능 플래그가 기본 OFF인 추천·주변 둘러보기의 로컬 연결. 실제 TourAPI/부산 API 호출, Edge 배포, 운영 설정 변경은 포함하지 않았다.
- 기존의 “공개 UI에서 production 연결 금지” 테스트를 현행 두 승인 진입점만 허용하도록 교체했다. 추천은 `v1Session`의 플래그 분기에서 동적 연결하고, 주변 둘러보기는 같은 플래그와 수동 중심 장소 선택을 모두 만족한 뒤 로드한다. 그 외 공개 UI의 우회·즉시 연결은 계속 거부한다.
- 주변 둘러보기 fixture로 OFF 상태에서 수동 장소 선택 후에도 live 로드 0회, ON 상태에서 수동 장소 선택 전 로드 0회, 선택 후 1회를 검증했다. 인증 세션 부재 시 facade가 초기화·원천 호출 전에 실패하는 계약은 `live-nearby-session.test.ts`에서 검증한다.
- 실시간 실패를 번들 장소의 성공으로 바꾸지 않는 계약과 추천의 세부 조회 12→6·최대 30은 기존 로컬 fixture에서 검증한다.
