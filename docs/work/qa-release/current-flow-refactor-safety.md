# 현재 기능 보존 회귀 — REFACTOR-SAFE-01

기준일: 2026-09-12. 사용자 요청: 과거 구현 정리 전에 현재 기능을 보호하는 테스트 확보.

## 변경과 범위

- `test/ui/current-flow-refactor-safety.test.mjs`: 고정 입력의 실행형 회귀 7개 추가.
- 이 문서: 검증 범위와 후속 경계 인계.
- 1곳/2곳 코스의 홈 이어가기에서 장소 순서·진행·실행 ID 보존.
- 실제 `PendingNavigationRouteBridge`를 hook host로 실행하여 준비 전 대기, 동일 요청 중복 방지, 새 요청, 다른 run/종료 요청 무시, 현재 화면 중복 진입 방지, 완료 요청 복귀 검증.
- 실제 completion composition을 통해 owner lifecycle에 payload/실패 결과를 전달하는지 검증. 미측정 체류를 계획 체류로 대체하지 않음.
- 실제 완료 controller와 StackRouter를 연결하여 저장 실패 시 진행 화면 유지, 같은 run 재시도, 이미 저장된 성공 처리, 중복 완료 방지, 기록 탭 종료 후 뒤로 진행 화면 복귀 불가를 검증.

## 변경하지 않은 경계

제품 코드, 데이터, migration, 운영 DB, 출시 설정, 기존 테스트 기대값 불변. 기존 문서 편집도 덮어쓰지 않음. 과거 화면 제거를 승인하거나 과거 조회를 유지 정책으로 확정하지 않는다.

## 검증 한계

이 테스트는 실제 함수·TSX 연결과 라우터를 실행하지만 React Native/iOS 렌더러는 아니다. 잠금화면 버튼 실행, 실제 재시작·영속 저장, 카카오맵 앱/웹 전환, 서버 RLS·개인화는 이 7개만으로 검증하지 않는다. 기존 관련 회귀 및 실기기 확인을 계속 유지한다. 파일 수나 통과 수를 코드 커버리지 %로 환산하지 않는다.

## 후속 작업

- 로그인 시 과거 저장 코스 조회 제거는 아직 미구현이므로 이번에 조회 0회 통과를 주장하지 않는다. 해당 리팩터링 직전에 실패하는 provider/port 호출 테스트를 먼저 추가한다.
- 과거 Execution 존치 테스트는 삭제 결정 후 대체한다. 현재 테스트를 통과시키기 위해 과거 화면을 복원하지 않는다.
- `execution/schedule.ts`, 현재 기록/개인화 repository, 현재 AppFlow 복원·Live Activity 연결을 공유 의존성으로 보존한다.
- DB 테이블/기록 삭제와 화면 정리를 분리한다. 이 작업은 데이터 삭제 권한이 아니다.
