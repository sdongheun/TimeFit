# QA 추천 기준선·실기기 관찰

## 범위

`QA-01`~`QA-05`, `RD-01~03`, `RD-DIAG-01/02`: 고정 fixture 회귀와 실제 iPhone의 제한된 추천 관찰을 분리한 워크스트림이다.

## 유지 계약

- 자동 회귀는 외부 API를 호출하지 않는 고정 fixture로만 한다.
- 실기기는 고정 입력·한 번 실행·안전 enum 기록을 지키며, cache 삭제·반복 호출로 결과를 만들지 않는다.
- 사상→서면의 8회 소진은 관찰 사실이며, 카탈로그/운영시간/제공사 중 단일 원인으로 단정하지 않는다.
