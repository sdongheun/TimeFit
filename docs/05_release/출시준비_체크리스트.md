## 현재 설계에서 확정한 최소 수집 원칙

1. 현재 위치는 추천 계산과 사용자가 선택한 코스에만 사용한다. 불필요한 연속 위치 추적이나 백그라운드 위치 권한은 요구하지 않는다.
2. 원본 위치 이력과 전체 경로는 개인화에 필요하지 않으면 저장하지 않는다. 저장하는 코스는 사용자가 내 코스에서 삭제할 수 있어야 한다.
3. AI 문장 보조를 도입하더라도 정확한 GPS 좌표, 이메일, 코스 전체 기록을 프롬프트에 보내지 않는다.
4. 위치 권한을 거절해도 지도 직접 선택으로 앱의 핵심 흐름을 사용할 수 있어야 한다.
5. 체류 개인화는 GPS로 도착·이탈을 자동 추정하지 않는다. 사용자가 명시한 완료 표본만 저장하고, 비로그인·Route Proxy anonymous Auth에는 연결하지 않는다.
6. 알림·Live Activity 시스템 권한과 앱의 체류 기록 동의를 구분한다. 시스템 권한은 상태와 설정 이동으로 안내하고 앱 안의 가짜 권한 토글로 표현하지 않는다.
