이용약관

버전 1.0 · 시행일 2026-09-09 · 운영자 신동흔

제1조 목적

이 약관은 신동흔이 운영하는 짜투리 앱과 관련 서비스의 이용 조건, 사용자와 운영자의 권리·의무 및 책임 범위를 정합니다.

제2조 서비스

  1. 짜투리는 부산에서 출발지, 약속 장소, 현재부터 최대 3시간의 남은 시간과 이동수단을 바탕으로 방문 장소 한 곳 또는 사용자가 고른 최대 두 곳의 코스와 예상 경로를 제안합니다.
  2. 로그인 없이 기본 추천·길찾기·기기 방문 기록을 이용할 수 있습니다. 계정을 만들면 방문 기록과 맞춤 추천 기능을 이용할 수 있습니다.
  3. 무료 제공 범위, 지원 지역과 외부 API 상황에 따라 일부 기능이 바뀌거나 중단될 수 있으며 중요한 변경은 가능한 방법으로 알립니다.

제3조 계정과 동의

  1. 회원가입에는 유효한 이메일과 비밀번호, 최신 이용약관과 개인정보 처리방침에 대한 명시 동의가 필요합니다.
  2. 계정 가입 대상은 만 14세 이상입니다. 신규 가입 시 필수 자기확인을 해야 하며, 이는 생년월일 수집이나 실제 연령 인증이 아닙니다.
  3. 사용자는 계정 정보를 안전하게 관리해야 합니다.
  4. 로그아웃은 계정과 서버 기록을 삭제하지 않습니다. 계정 삭제는 앱의 내정보 → 프로필 관리에서 시작할 수 있습니다.
  5. 비로그인 기기 기록은 자동으로 계정에 합쳐지지 않습니다. 사용자가 명시적으로 가져오기를 승인한 기록만 연결됩니다.

제4조 추천과 길찾기

  1. 추천, 이동시간, 운영시간과 도착 여유는 공개 데이터, 외부 경로 서비스와 사용자 입력에 따른 예상값입니다.
  2. 교통, 임시 휴무, 행사, 예약, 입장 제한과 날씨에 따라 실제 상황이 달라질 수 있으므로 출발 전 최신 장소 정보와 지도 경로를 확인해야 합니다.
  3. 짜투리는 긴급구조, 안전 운행, 의료·법률 판단을 위한 서비스가 아닙니다.
  4. 사용자는 부산의 출발지와 약속 장소를 검색하거나 지도에서 직접 선택합니다. 외부 카카오맵 앱이 없으면 가능한 경우 웹 경로로 연결합니다.

제5조 맞춤 추천

  1. 일반 로그인과 별도 동의를 모두 받은 뒤 새 코스에서 사용자가 명시적으로 확인한 도착·출발·완료 기록만 사용합니다.
  2. 비로그인 기록, 가져온 기록과 동의 전 기록은 학습에 사용하지 않습니다.
  3. 사용자는 언제든 동의를 끄거나 맞춤 기록을 초기화할 수 있습니다. 개인화는 안전·운영시간·경로 조건을 완화하지 않습니다.

제6조 사용자의 의무

  • 타인의 계정이나 개인정보를 무단 사용하지 않습니다.
  • 서비스·서버·외부 API에 비정상 요청이나 보안 침해를 시도하지 않습니다.
  • 앱의 데이터·사진·지도·상표를 권리자의 허락 범위를 넘어 이용하지 않습니다.
  • 법령과 제3자의 권리를 침해하지 않습니다.

제7조 외부 서비스와 권리

앱 코드·구성과 브랜드의 권리는 운영자 또는 정당한 권리자에게 있습니다. 장소 정보·사진·지도·경로에는 부산 관광 콘텐츠 제공자, Kakao 등 원권리자의 조건이 적용될 수 있습니다. 외부 지도나 웹페이지를 열면 해당 사업자의 약관과 개인정보 처리방침이 적용됩니다.

제8조 서비스 제한과 책임

점검, 장애, 천재지변, 공급자 중단, 법령 또는 정책 변경으로 서비스가 일시 제한될 수 있습니다. 운영자는 고의 또는 중대한 과실이 없는 경우 관계 법령이 허용하는 범위에서 무료 서비스의 불가피한 중단, 사용자 입력 오류와 외부 정보 변동에 따른 책임을 부담합니다. 이 약관은 소비자에게 법률상 보장된 권리를 제한하지 않습니다.

제9조 계약 해지와 데이터

사용자는 앱에서 계정 삭제를 시작하거나 이용을 중단할 수 있습니다. 앱 삭제만으로 서버 계정이 삭제되지는 않습니다. 데이터 처리와 삭제 범위는 개인정보 처리방침을 따릅니다.

제10조 변경과 준거법

약관을 변경하면 시행일과 내용을 사전에 알립니다. 대한민국 법령을 준거법으로 하며 분쟁은 관계 법령이 정한 절차와 관할에 따릅니다.

장소 선택과 경로 기능

짜투리는 사용자가 검색하거나 지도 핀으로 직접 고른 장소의 이름·주소·좌표를 주소 표시, 주변 장소 추천과 경로 안내에 사용합니다. 기기의 GPS 위치나 위치 권한을 사용하지 않으며, 도착·출발·완료는 사용자가 앱 또는 Live Activity에서 직접 확인합니다. 선택 장소와 경로의 처리 내용은 개인정보 처리방침에서 확인할 수 있습니다.
