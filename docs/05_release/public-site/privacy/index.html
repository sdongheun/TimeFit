개인정보 처리방침

버전 1.0 · 시행일 2026-09-09 · 운영자 신동흔

짜투리는 부산에서 약속 전 최대 3시간 안에 들를 장소와 최대 두 곳의 코스를 제안합니다. 운영자는 서비스에 필요한 정보만 처리하며, 사용 목적과 실제 데이터 흐름을 아래와 같이 안내합니다.

1. 처리하는 정보와 목적

기능처리 항목목적
회원가입·로그인이메일, 비밀번호, 사용자 ID, 동의 문서·버전·시각계정 생성, 인증, 보안, 동의 이력 관리
선택 프로필닉네임앱 안의 프로필 표시
장소·경로 추천검색 또는 지도 핀으로 직접 선택한 출발지·약속 장소의 이름·주소·정확 좌표, 이동수단, 요청 시각, 추천·경로 결과장소 검색, 예상 이동시간과 가능한 코스 계산, 지도 표시

보안세션, 접속 요청 정보, 익명 사용자 ID, CAPTCHA 결과와 브라우저·네트워크 신호인증, API 보호, 부정 이용 방지

비로그인 완료 기록, 활성 코스, Live Activity 진행, 로컬 알림과 앱 진단은 원칙적으로 기기 안에 저장되며 짜투리 서버로 자동 전송하지 않습니다. 다만 사용자가 장소를 검색하거나 지도 핀을 확정해 장소·경로를 계산하고 외부 지도·사진을 열 때에는 필요한 검색어·선택 장소의 좌표·네트워크 정보가 외부 서비스에 전달될 수 있습니다.

체류 기반 맞춤 추천

로그인하고 별도로 동의한 사용자가 새 코스에서 도착·출발·완료를 직접 확인한 경우에만 완료·코스·장소 식별자, 분류, 실제 체류 분, 분 단위 완료 시각, 사용자 ID와 동의 정보를 처리합니다. 같은 세부 분류의 유효 표본이 3개 이상이면 최근 최대 5개의 중앙값을 안전 범위 안에서 다음 추천에 반영합니다.

비로그인 기록, 나중에 가져온 기록, 동의 전 기록과 일반 알림 반응은 학습하지 않습니다. 동의를 끄면 새 표본 제출·조회·추천 반영을 중단합니다. 기존 서버 표본까지 지우려면 앱의 맞춤 기록 초기화를 사용합니다.

2. 보유와 삭제

항목보유 기준삭제
계정·동의·프로필회원 탈퇴 완료 때까지. 별도 법정 보존 의무가 있으면 해당 기간계정과 연결된 DB 행 및 Auth 계정 삭제. 보안 로그와 백업 반영에는 제공자 정책에 따른 시간이 걸릴 수 있음
저장 코스·계정 방문 기록사용자가 기록을 삭제하거나 탈퇴할 때까지계정별 삭제. 방문 기록 삭제와 맞춤 체류 표본 초기화는 별도 동작
체류 표본생성 후 최근 180일을 추천 유효 범위로 사용맞춤 기록 초기화·탈퇴 시 삭제 대상. 만료 조회와 별도 정리 함수가 있으나 180일 직후 물리 삭제를 보장하지 않음
기기 기록기능 수행 중 또는 사용자가 기기에서 유지하는 동안완료·취소·교체 시 진행 자료 정리, 앱의 제공 기능 또는 앱 삭제와 iOS 정책에 따름
경로 임시 저장공개 경로는 기본 15분 동안 사용하며 서버 정책상 최대 24시간 범위유효기간이 지나면 조회에서 제외하고 시스템 정리 대상으로 처리

로그아웃과 계정 삭제는 다릅니다. 계정 삭제는 앱의 내정보 → 프로필 관리에서 시작할 수 있습니다. 경로 임시 저장, 외부 제공자 로그와 법정 보존 자료처럼 개인 계정과 범위가 다른 정보까지 즉시 모두 삭제된다고 보장하지 않습니다.

4. 선택 장소의 좌표와 경로 처리

짜투리는 출시 버전에서 기기의 GPS 위치를 요청하거나 위치 권한을 사용하지 않습니다. 사용자는 부산의 출발지, 약속 장소 또는 주변 둘러보기 기준점을 검색하거나 지도에서 핀을 찍어 직접 선택합니다. 지도의 부산 기본 보기는 화면의 초기 중심일 뿐 사용자의 위치나 선택으로 저장되지 않습니다.

장소 검색어는 카카오에 전달되며 검색 요청에 기기 현위치 좌표를 자동으로 붙이지 않습니다. 지도 핀을 확정하면 선택한 정확 좌표가 주소 표시를 위해 카카오에 전달됩니다. 추천·경로 계산에는 선택한 출발지·약속 장소·방문 장소의 정확 좌표와 인증 정보가 짜투리 서버에 전달되고, 서버는 경로 계산에 필요한 좌표를 카카오에 전달합니다. 카카오 경로 요청에는 짜투리 계정 ID나 약속 시각을 넣지 않습니다.

코스에서 길찾기를 누르면 해당 구간의 출발·도착 이름과 좌표, 이동수단이 카카오맵 앱 또는 웹에 전달됩니다. 앱은 GPS로 도착이나 방문을 판정하지 않습니다. 도착·출발·완료와 체류시간은 사용자가 앱 또는 Live Activity에서 직접 누른 버튼과 그 시간 차를 기준으로 처리합니다. 예상 이동시간·운영시간·도착 여유는 실제 상황과 다를 수 있으므로 출발 전 지도와 장소의 최신 정보를 확인해야 합니다.
