## TimeFit이 제공하는 기능

TimeFit은 부산에서 다음 일정 전 남은 시간을 활용할 장소와 이동 코스를 제안합니다. 현재 위치를 허용하거나 부산의 출발지와 약속 장소를 직접 입력할 수 있습니다. 추천은 기본 한 장소이며, 검증된 후보 중 사용자가 직접 선택하면 최대 두 장소 코스를 만들 수 있습니다.

예상 이동시간과 운영시간은 실제 교통·임시 휴무·예약·행사 상황과 다를 수 있습니다. 출발 전 장소 상세와 카카오맵에서 최신 정보를 확인해 주세요.

## 위치·알림 없이 이용하기

- 위치 권한을 허용하지 않아도 출발지와 약속 장소를 검색하거나 지도에서 직접 선택할 수 있습니다.
- 알림 또는 Live Activity를 허용하지 않아도 앱 안에서 코스를 확인하고 외부 길찾기를 열 수 있습니다.
- 카카오맵 앱이 없으면 지원되는 경우 웹 지도로 연결됩니다.

## 계정과 기록

- 로그인 없이 만든 완료 기록은 기기에 저장됩니다.
- 로그인 후 만든 계정 기록은 해당 계정에 동기화됩니다.
- 이전 비로그인 기록은 사용자가 직접 가져오기를 승인할 때만 계정에 연결됩니다.
- 로그아웃은 계정 삭제가 아닙니다. 계정 삭제는 `내정보 → 프로필 관리 → 계정 삭제`에서 시작합니다.
- 맞춤 추천이 출시 빌드에 포함된 경우, `내정보 → 권한 및 맞춤 추천`에서 별도 동의를 끄거나 기록을 초기화할 수 있습니다.

## 문제 해결

1. 추천 결과가 없으면 출발지·약속 장소·시간 범위를 다시 확인하고 잠시 후 재시도해 주세요.
2. 위치가 맞지 않으면 iOS 설정에서 TimeFit 위치 권한을 확인하거나 위치를 직접 입력해 주세요.
3. 길찾기가 열리지 않으면 네트워크 연결과 카카오맵 설치 상태를 확인해 주세요.
4. 운영시간이 불확실한 장소는 카카오맵 또는 장소 공식 안내에서 확인해 주세요.
5. 삭제 결과가 ‘확인 중’이면 같은 계정과 같은 삭제 요청으로 다시 확인해 주세요.
