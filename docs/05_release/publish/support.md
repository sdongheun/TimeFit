## 짜투리가 제공하는 기능

짜투리는 부산에서 다음 일정 전 최대 3시간을 활용할 장소와 이동 코스를 제안합니다. 부산의 출발지와 약속 장소를 검색하거나 지도에서 직접 선택할 수 있습니다. 추천은 기본 한 장소이며, 시간·운영시간·경로 조건을 확인한 후보 중 사용자가 직접 선택하면 최대 두 장소 코스를 만들 수 있습니다.

예상 이동시간과 운영시간은 실제 교통·임시 휴무·예약·행사 상황과 다를 수 있습니다. 출발 전 장소 상세와 카카오맵에서 최신 정보를 확인해 주세요.

## 장소 선택·알림 이용 안내

- 출발지와 약속 장소는 검색하거나 지도에서 핀을 찍어 직접 선택합니다. 지도의 부산 기본 보기는 선택값으로 저장되지 않습니다.
- 알림 또는 Live Activity를 허용하지 않아도 앱 안에서 코스를 확인하고 외부 길찾기를 열 수 있습니다.
- 카카오맵 앱이 없으면 지원되는 경우 웹 지도로 연결됩니다.

## 계정과 기록

- 로그인 없이 만든 완료 기록은 기기에 저장됩니다.
- 로그인 후 만든 계정 기록은 해당 계정에 동기화됩니다.
- 이전 비로그인 기록은 사용자가 직접 가져오기를 승인할 때만 계정에 연결됩니다.
- 승인되지 않거나 가져오기 결과가 불명확한 비로그인 원본은 기기에 유지됩니다.
- 로그아웃은 계정 삭제가 아닙니다. 계정 삭제는 `내정보 → 프로필 관리 → 계정 삭제`에서 시작합니다.
- 맞춤 추천은 로그인과 별도 동의가 필요합니다. `내정보 → 권한 및 맞춤 추천`에서 동의를 끄면 새 학습과 추천 반영을 중단하고, 기존 서버 표본까지 지우려면 맞춤 기록 초기화를 사용합니다. 가져온 비로그인 기록은 맞춤 학습에 쓰지 않습니다.

## Live Activity

- 코스에서 길찾기 버튼을 누르면 이동 중 상태로 바뀝니다. Live Activity를 허용한 경우 앱과 같은 진행 상태를 확인할 수 있습니다.
- 웹 지도를 닫고 돌아와도 진행 상태는 유지됩니다. 실제로 도착한 뒤 `도착했어요`를 눌러 주세요. 길찾기를 여는 것만으로 도착이나 체류가 기록되지는 않습니다.
- 최종 목적지 구간에서는 Live Activity의 `도착 후 코스 마치기`로 앱의 기존 완료 절차를 이어갈 수 있습니다.
- 도착 확인 옆의 `5분 뒤 다시 알림` 동작은 현재 출시 화면에서 제공하지 않습니다.
- Live Activity를 끄거나 알림을 거절해도 앱 안의 진행과 명시 완료를 사용할 수 있습니다.

## 문제 해결

1. 추천 결과가 없으면 출발지·약속 장소·시간 범위를 다시 확인하고 잠시 후 재시도해 주세요.
2. 선택한 장소가 맞지 않으면 출발지 또는 약속 장소를 다시 검색하거나 지도 핀을 옮겨 확정해 주세요.
3. 길찾기가 열리지 않으면 네트워크 연결을 확인하고 다시 시도해 주세요. 카카오맵 앱이 없으면 지원되는 웹 지도를 이용할 수 있습니다.
4. 운영시간이 불확실한 장소는 카카오맵 또는 장소 공식 안내에서 확인해 주세요.
5. 삭제 결과가 ‘확인 중’이면 같은 계정과 같은 삭제 요청으로 다시 확인해 주세요.
