# 짜투리 공급자 고지 문의문 — 내부 발송 준비본

기준일: 2026-09-09  
상태: **발송 전 초안**. 이 문서 작성 과정에서 문의를 발송하거나 계약에 동의하지 않았다.

계정 화면과 공개 자료로 확인된 사실은 다시 묻지 않는다. 비밀번호, API key, token, sitekey, 사용자 로그·좌표, 계약 원본과 개인 전화번호를 문의 본문에 넣지 않는다. 답변에는 가능한 경우 적용 상품명·문서명·조항·URL·시행일을 요청한다.

## 1. Supabase 공식 지원 채널

**수신처:** 로그인된 Supabase Dashboard의 공식 Support 문의 화면. 기존 근거에서 공개 이메일 주소를 확인하지 못했으므로 임의 주소를 만들지 않는다.  
**상태:** 미발송·답변 없음.

**제목**

```text
Free Plan의 기본 이메일·Edge Function·서비스 로그 처리 범위 문의
```

**본문**

```text
안녕하세요. 대한민국에서 iOS 앱 ‘짜투리’를 운영 준비 중이며, 개인정보 처리방침의 처리위탁·국외 이전 항목을 실제 서비스 설정과 맞추기 위해 문의드립니다.

현재 Free Plan / SUPABASE PTE. LTD. / DPA Version 1 (August 1, 2026)을 사용하고 있습니다. 프로젝트 DB/Auth와 route-proxy Edge Function은 ap-northeast-2이며, Custom SMTP·Log Drains·Cron Integration은 사용하지 않고 Free Plan 백업은 제공되지 않는 것으로 확인했습니다.

공개 문서와 계정 화면에서 확인하지 못한 아래 사항만 안내 부탁드립니다.
1. Custom SMTP를 사용하지 않을 때 인증 이메일 처리에 실제 적용되는 수령자·하위처리자와 처리 국가는 어디입니까?
2. Edge Function, Auth, API와 보안·지원 로그에 적용되는 처리 국가와 보유 기준은 무엇입니까?
3. ap-northeast-2 지정에도 서비스 제공·지원·보안을 위해 다른 국가에서 처리 또는 접근되는 예외가 있다면, 대상 정보·목적·시기 또는 방법·수령자를 확인할 공식 문서는 무엇입니까?
4. 계정 삭제 뒤 위 로그 또는 운영 복사본에 적용되는 삭제·보존 예외가 있다면 기준을 확인할 공식 문서는 무엇입니까?

고정 기간이 상품 또는 로그 유형마다 다르면 각 유형별 기준과 공식 문서 URL을 부탁드립니다. 계정 비밀값이나 사용자 로그는 제공하지 않겠습니다.
```

**영향:** 개인정보 처리방침 제2·3절의 기본 이메일·제공자 로그·국외 처리, App Privacy의 Email Address·Identifiers·Diagnostics. 답변 전에는 서울 DB/route 처리를 모든 Supabase 처리의 국내 완료로 확대하지 않는다.

## 2. Cloudflare 개인정보 문의

**수신처:** `dpo@cloudflare.com` — 기존 확인한 [Turnstile Privacy Addendum](https://www.cloudflare.com/turnstile-privacy-policy/)의 공개 문의처.  
**상태:** 미발송·답변 없음.

**제목**

```text
Turnstile·Workers Free의 최종 사용자 데이터 처리 범위 문의
```

**본문**

```text
안녕하세요. 대한민국에서 iOS 앱 ‘짜투리’를 운영 준비 중이며, 로그인과 비로그인 추천 보호에 Cloudflare Turnstile 및 Worker를 사용합니다.

현재 Workers Free / Cloudflare, Inc. / DPA Version 6.4 (April 3, 2026)이며 Managed Turnstile과 Worker가 활성 상태입니다. 운영자가 선택하는 Workers Logs와 Traces는 비활성입니다.

개인정보 고지를 위해 공개 문서에서 확인하지 못한 아래 사항을 문의드립니다.
1. Turnstile의 사이트 보호 목적 processor 처리와 탐지 개선 목적 controller 처리에 각각 포함되는 최종 사용자 정보는 무엇입니까?
2. 각 목적에 적용되는 처리 국가·수령자 또는 하위처리자·보유 기준은 무엇입니까?
3. Workers Logs와 Traces가 비활성이어도 서비스 제공·보안 목적으로 유지되는 기본 요청 또는 보안 기록이 있다면 항목·목적·보유 기준은 무엇입니까?
4. 대한민국 최종 사용자에 대한 위 내용을 확인할 최신 공식 문서·조항 URL을 알려주실 수 있습니까?

계정 secret, sitekey, token과 사용자 요청 로그는 제공하지 않겠습니다.
```

**영향:** 개인정보 처리방침 제3절의 보안 처리·국외 이전, App Privacy의 Device ID·Diagnostics, 향후 Cloudflare Pages 호스팅 고지. 운영자 선택 로그 비활성을 Cloudflare 기본 처리0으로 표현하지 않는다.

## 3. Kakao 개인정보보호부서·고객센터

**수신처:** [카카오 개인정보처리방침](https://www.kakao.com/policy/privacy/)에 안내된 개인정보보호부서/고객센터 `1577-3754`. 전화 또는 해당 공식 고객센터가 안내하는 문의 경로 중 하나만 사용한다.  
**상태:** 미발송·답변 없음.

**문의 제목 또는 전화 첫 문장**

```text
Kakao Developers Local·Maps·도보/대중교통 API의 개인정보 처리 역할 문의
```

**본문 또는 통화 전달문**

```text
안녕하세요. 대한민국 iOS 앱 ‘짜투리’에서 Kakao Developers의 다음 기능을 사용하고 있습니다.

- Local: 키워드 장소 검색, 좌표→행정구역, 좌표→주소, 주소 검색
- Maps JavaScript
- REST 경로: walk.json, publictraffic.json

앱은 기능 실행에 필요한 검색어·주소·정확 좌표·이동수단을 전송하며, 경로 요청에는 짜투리 계정 ID와 약속 시각을 넣지 않습니다.

개인정보 처리방침과 동의 화면을 정확히 작성하기 위해 다음 사항을 상품별로 확인 부탁드립니다.
1. 각 상품에서 위 정보는 개발자인 운영자의 지시에 따른 처리위탁 정보입니까, 카카오의 독자 목적을 위한 제3자 제공 정보입니까?
2. Kakao 플랫폼 서비스 약관 제11조 제7·8항은 위 상품별 요청에 어떻게 적용됩니까?
3. 요청 로그의 처리 목적·보유 기준·처리 국가와 수령자를 확인할 상품별 공식 문서는 무엇입니까?
4. 운영자가 최종 사용자에게 받아야 할 동의 또는 공개해야 할 필수 항목이 있다면 적용 문서·조항을 알려주실 수 있습니까?

API key, 사용자 좌표와 로그 원문은 제공하지 않겠습니다.
```

**영향:** 개인정보 처리방침 제3·4절, 가입 시 별도 동의 필요 여부, App Privacy의 Precise Location·Search History, 심사 메모. 무료 API 사용과 호출량을 개인정보 미처리의 근거로 사용하지 않는다.

## 4. 국내 개인정보 전문 검토

**수신처:** 사용자가 선정한 개인정보·위치정보 전문 자문가 또는 공공 상담기관. 특정 업체·주소는 아직 선정되지 않아 만들지 않는다. 이미 접수한 위치기반서비스 문의는 재접수하지 않는다.  
**상태:** 수신처 선정 전·미발송.

**제목**

```text
외부 API·클라우드 처리의 위탁·제3자 제공·국외 이전 고지 범위 검토 요청
```

**본문**

```text
대한민국에서 개인이 운영 준비 중인 iOS 앱 ‘짜투리’의 개인정보 처리 고지 범위를 검토받고자 합니다. 위치기반서비스 신고·면제/특례와 별도 위치 약관 여부는 이미 공식 문의를 접수했으므로 이번 요청에서 같은 질문을 반복하지 않습니다.

확인된 기술 사실은 다음과 같습니다.
- Supabase: SUPABASE PTE. LTD. Free Plan/DPA v1, DB/Auth·주요 경로 함수 서울, 기본 인증 이메일과 관리형 서비스 로그 사용 가능
- Kakao: Local·Maps JavaScript·REST 도보/대중교통에 검색어·주소·좌표·이동수단 전송
- Cloudflare: Turnstile·Worker로 로그인/비로그인 추천 보호, 운영자 선택 Workers Logs·Traces 비활성
- 선택 동의한 로그인 사용자의 완료·체류 기록을 제한적으로 개인화에 사용

각 처리에 대해 아래를 구분해 검토 부탁드립니다.
1. 운영자 기준 처리위탁, 제3자 제공 또는 각각에 해당하지 않는 처리인지
2. 국외 이전이 있다면 적용 가능한 근거와 공개·동의가 필요한 정확한 항목
3. 가입 시 별도 동의가 필요한 항목과 개인정보 처리방침 공개만으로 가능한 항목
4. 공급자가 고정 보유기간·국가를 회신하지 않은 경우 허위 기간을 만들지 않고 적법하게 표시하는 방법
5. Cloudflare Turnstile의 processor/controller 목적을 국내 고지에서 나누는 방법

검토 결과에는 적용 법조항, 필요한 문구와 영향을 받는 문서 절을 구분해 주시기 바랍니다.
```

**영향:** 개인정보 처리방침 제3절, 가입 동의 구조, App Privacy 최종값과 공개 가능 판정. 공급자의 기술 답변을 국내 법적 결론으로 자동 승격하지 않는다.

## 5. 이미 접수한 위치 문의

새 문의문을 만들거나 재발송하지 않는다. 기존 문의 답변이 도착하면 신고·면제/특례, 별도 위치 약관, 주소·전화·위치정보관리책임자, 위치정보 이용·제공사실 확인자료 중 **답변이 직접 다룬 항목만** 개인정보 처리방침·이용약관·지원 안내에 반영한다. 공급자 로그·국외 이전을 다루지 않은 답변으로 위 1~4절을 닫지 않는다.
