## 1. 처리하는 개인정보와 목적

TimeFit은 부산에서 약속 전 남은 시간에 맞는 장소와 경로를 제안합니다.

| 기능 | 처리 항목 | 목적 | 처리 근거 초안 |
| --- | --- | --- | --- |
| 회원가입·로그인 | 이메일, 비밀번호, 사용자 ID, 가입 동의 문서·버전·동의 시각 | 계정 생성, 인증, 보안, 동의 이력 관리 | 서비스 계약의 체결·이행 및 필수 동의 |
| 선택 프로필 | 닉네임 | 앱 안에서 사용자 프로필 표시 | 사용자 선택 동의 또는 계약 이행 범위 검토 필요 |
| 장소·경로 추천 | 현위치 또는 사용자가 입력한 출발지·약속 장소의 이름·주소·정확 좌표, 이동수단, 요청 시각, 추천·경로 결과 | 장소 검색, 예상 이동시간과 가능한 코스 계산, 지도 표시 | 위치정보 동의 및 서비스 제공에 필요한 처리 |
| 코스 저장·기록 | 출발지·약속 장소·방문 장소의 이름·좌표, 코스 시각·이동수단·추천 snapshot, 완료 시각·방문 장소 | 사용자가 저장한 코스와 방문 기록 제공 | 서비스 계약의 이행 |
| 계정 보안·오남용 방지 | 세션·접속 요청 정보, anonymous 사용자 ID, CAPTCHA 결과와 관련 브라우저·네트워크 신호 | 인증, API 보호, 부정 이용 방지 | 정당한 이익 또는 계약 이행 여부 검토 필요 |

비로그인 완료 기록, 활성 코스, Live Activity 진행, 로컬 알림과 앱 진단은 원칙적으로 기기 안에 저장되며 TimeFit 서버로 자동 전송하지 않습니다. 다만 장소·경로를 계산하거나 외부 지도·사진을 열 때 해당 요청에 필요한 좌표·검색어·네트워크 정보가 외부 서비스에 전달될 수 있습니다.

### 조건부: 체류 기반 맞춤 추천

이 절은 원격 migration과 실제 서버 저장·조회·삭제 검증을 통과하고 출시 빌드에서 기능이 활성화될 때만 공개본에 포함합니다.

로그인한 사용자가 별도로 동의하고, 동의 후 시작한 코스에서 도착·출발·완료를 직접 확인한 경우에만 다음 항목을 처리합니다.

- 완료 event와 코스·장소 식별자, 장소 category·subCategory
- 실제 체류 분, 분 단위 완료 시각
- 사용자 ID와 동의 epoch·revision

같은 category·subCategory의 유효 표본이 3개 이상이면 최근 최대 5개의 중앙값을 안전 범위 안에서 다음 추천에 반영합니다. 비로그인 기록, 나중에 가져온 guest 기록, 동의 전 기록, 일반 알림 반응은 학습하지 않습니다. 사용자는 내정보에서 동의를 끄거나 맞춤 기록을 초기화할 수 있습니다.

## 2. 보유기간과 파기

| 항목 | 보유기간 초안 | 파기 방법 |
| --- | --- | --- |
| 계정·가입 동의·프로필 | 회원 탈퇴가 완료될 때까지. 법령상 별도 보존 의무가 확정되면 그 기간 | DB 행·Auth 계정 삭제. 백업·로그 반영 기간은 **[운영 설정 확인 필요]** |
| 저장 코스·계정 방문 기록 | 사용자가 개별/전체 삭제하거나 회원 탈퇴할 때까지 | 계정별 DB 삭제·cascade |
| 조건부 체류 표본 | 생성 후 최대 180일 또는 사용자의 맞춤 기록 초기화·회원 탈퇴 중 먼저 도래하는 때 | 서버 표본·파생 profile 삭제. 운영 purge와 backup 반영은 **[확인 필요]** |
| 비로그인 완료·활성 코스·Live Activity·로컬 알림·진단 | 기능 수행 중 또는 사용자가 기기에서 유지하는 동안. 일부 완료/후기 기록은 최대 1,000건 상한만 있고 기간이 없음 | 정상 완료·취소·교체 시 진행 자료 정리, 앱 삭제 또는 제공되는 삭제 기능. 비로그인 전체 삭제 수단은 **[확인/보완 필요]** |
| route cache | public route 기본 15분 유효, 최대 24시간 범위의 서버 정책. 실제 운영값·물리 purge는 **[확인 필요]** | 만료 조회 제외와 purge job |

보유 목적이 끝난 개인정보는 복구하기 어렵게 파기합니다. 법령에 따라 보존해야 하는 정보가 생기면 다른 정보와 분리해 보관하고 항목·근거·기간을 이 방침에 표시합니다.

## 4. 위치정보와 권한

TimeFit은 사용자가 위치 기반 기능을 선택했을 때 iOS의 ‘앱을 사용하는 동안’ 위치 권한을 요청합니다. 백그라운드 위치와 GPS 자동 도착 판정은 사용하지 않습니다. 권한을 거절해도 부산의 출발지와 약속 장소를 직접 검색하거나 지도에서 선택해 핵심 추천 흐름을 이용할 수 있습니다.

현위치 또는 수동 위치는 주소 표시와 경로 계산을 위해 Kakao 및 Supabase Edge에 전달될 수 있습니다. 외부 카카오맵을 열면 출발·도착 이름과 좌표, 이동수단이 카카오맵 앱 또는 웹에 전달됩니다. 예상 이동시간·운영시간·도착 여유는 실시간 상황과 다를 수 있으므로 출발 전 실제 지도와 장소 정보를 확인해야 합니다.

TimeFit의 위치기반서비스사업 해당 여부, 신고·면제 요건, 위치정보 이용약관과 관리책임자 표시는 **[전문 검토 필요]**입니다.

## 5. 이용자의 권리와 행사 방법

사용자는 앱에서 다음을 할 수 있습니다.

- 닉네임 변경·삭제
- 계정 방문 기록 개별 또는 전체 삭제
- 조건부 맞춤 추천 동의 on/off 및 기록 초기화
- 프로필 관리에서 계정 삭제 시작
- iOS 설정에서 위치·알림·Live Activity 권한 변경

개인정보 열람·정정·삭제·처리정지와 동의 철회는 **[지원 이메일]**로 요청할 수 있습니다. 요청자의 본인 여부를 확인할 수 있으며, 법령상 제한 사유가 있으면 이유와 이의 제기 방법을 안내합니다. 계정 삭제와 로그아웃은 다릅니다. 계정 삭제 결과가 불확실하면 앱은 같은 요청으로 다시 확인하도록 안내합니다.

## 6. 아동의 개인정보

현재 구현에는 만 14세 미만 법정대리인 동의 확인 절차가 없습니다. 따라서 출시 전 아래 중 하나를 확정하고 실제 가입 경로와 일치시켜야 합니다.

1. 만 14세 미만의 계정 생성을 막는 검증 가능한 가입 정책을 구현·고지하거나,
2. 법정대리인 동의와 확인 절차를 제공하고 아동용 안내를 마련합니다.

문구만으로 연령 제한을 선언하고 누구나 가입 가능한 상태를 유지해서는 안 됩니다.
