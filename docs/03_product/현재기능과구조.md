# 현재 기능과 코드 연결 구조

기준일 2026-09-12 / 검사 소스 `30c0284`. DOCS-CURRENT-STRUCTURE-01. 사용자 요청에 따른 문서 정합성 정리이며 신규 기능 정책을 만들지 않는다. 정적 호출 추적과 앞선 로컬 테스트 결과를 근거로 한다. App Store 배포는 사용자 보고이고, 출시 IPA와 소스의 동등성을 별도 검증한 것은 아니다.

## 1. 앱의 주 흐름

```text
App.tsx
 ├─ Home → TimeSetup → Results → PlaceDetail → Results(선택 상태 반영)
 │                       └─────────────────→ CourseConfirm(review/active)
 ├─ NearbyBrowse → 장소 목록/마커/상세 → 독립 카카오맵 길찾기
 ├─ ActivityRecord → 방문 통계·필터·삭제
 └─ Profile → Login / ProfileManagement / 문서·권한·맞춤 추천
```

근거: `App.tsx`, `src/ui/mainTabNavigation.ts`, `HomeScreen.tsx`, `TimeSetupScreen.tsx`, `ResultsScreen.tsx`. 탭 대상은 메인·주변 둘러보기·기록·내정보다. 메인 내부는 스택 이동, 탭 전환은 해당 탭으로 reset한다. `CourseConfirm`의 확인/진행은 같은 화면 상태이며 별도 `Execution`으로 넘기는 것이 신규 코스의 주 흐름은 아니다.

## 3. 저장·외부 서비스 경계

- 현재 완료 entry: `courseCompletionComposition → ownedCourseLifecycle → releaseIdentitySupabase → releaseIdentityPersonalizationRuntime`. 과거 로컬 repository가 있다는 이유로 모든 완료를 로컬 전용이라고 설명하지 않는다.
- 회원 방문: `account_course_completions`/`account_course_completion_places`, 닉네임: `profiles`. 동의·표본은 해당 RPC/repository로 연결된다. `courses`/`course_stops`는 저장 코스 호환 경로와 구별한다.
- 공개 URL: `ui/publicDocuments.ts`, 가입 문서 조회: `get_signup_consent_documents`. 운영 registry 행과 이메일 인증 설정은 코드만으로 현재 값을 확정하지 않는다.
- 경로 proxy: `v1Session.recommendationPortsFor`의 설정 분기로 활성화. 비활성/테스트용 legacy adapter는 TMAP 보행용. ODsay 신규 요청 제거, 과거 저장 source 문자열 보존.
- Kakao 지도·검색, Supabase 인증/저장/proxy, Cloudflare CAPTCHA·문서 호스팅을 구분한다. 사진은 [출시 자산 감사](../work/data-curation/release-assets-final.md)와 allowlist 계약을 따른다. 이번 정리로 공개 개인정보 고지를 수정·재배포하지 않는다.

## 5. 구현 편차와 확정하지 않은 사실

`UX-COLOR-01`은 짙은 버튼의 활성 텍스트를 흰색 계열로 정했지만, `ResultsScreen`의 `moreButtonText`에는 `#9dcbff`가 남아 있다. 이는 구현 편차이지 파란 행동 텍스트 정책이 부활한 것이 아니다. 후속 UI 점검 대상으로 남긴다.

과거 `원격 미적용`, `자동화 미착수`, `UI 연결 전`은 작성 당시 상태다. 소스 연결은 위와 같이 정정하지만 운영 DB 전체 상태·미검증 시나리오까지 일괄 완료로 바꾸지 않는다.
