# TimeFit UIUX 테스트 명세

> 목적: 사용자 검토 과정에서 발견한 UIUX 문제를 재발하지 않도록 요구사항 ID, 화면 상태, 자동화 조건으로 관리한다. 이 문서는 이후 Maestro 또는 Detox E2E 테스트의 시나리오 원본이다.

## 사용 규칙

- 새 UIUX 피드백은 기존 ID와 `동일`, `보완`, `충돌` 여부를 먼저 판단한다.
- 충돌이면 기존 요구사항을 임의로 덮어쓰지 않고 사용자 결정 뒤 상태를 `대체됨`으로 바꾼다.
- `자동화 전제`의 `testID`와 고정 위치·시각·API 응답 주입이 준비되기 전에는 수동 시나리오로 확인한다.
- 자동화가 추가되면 이 문서의 상태와 [테스트 현황](../테스트.md)을 함께 갱신한다.

### UXV-46 — 코스 상세의 선택 후 도보 연결 보충

- **관계:** UXV-44의 `상세 진입 route 0회`를 부분 교체한다. 추천·transit 재조회 0회는 유지하고, 선택한 코스의 50m 초과 누락 endpoint walk만 최대 4회 호출할 수 있다.

### UXV-47 — 최대 2곳 제한 선택·취소 복원

- **관계:** UXV-20·29·44·45를 보완하고 기존 카드 전체 tap 상세 선진입을 교체한다. one-stop 확인·진행은 선택 후 fixed CTA와 CourseConfirm에서 유지하며, 1~3곳 자동 코스·자유 장바구니를 재활성화하지 않는다.
- **기대 결과:** 추천 화면의 실제 표시 one-stop 카드 tap에서 A 선택이 시작된다. 선택 전과 동일한 Results tree·ScrollView·헤더·시간 요약을 유지한 채 A는 safe-area 아래 compact sticky tray에 고정되고, 기존 one-stop 카드 영역만 같은 자리에서 B 후보/검증 중 skeleton으로 교체된다. exact 성공 B는 안정된 순서로 점진 표시한다. 선택 전 하단 CTA는 없고, A 선택 뒤 `이 장소로 코스 보기`, B 선택 뒤 `선택한 2곳 코스 보기`를 safe-area 위에 고정한다. B 선택 자체는 navigation·추가 route 0이며 CTA에서만 선택 snapshot 상세를 연다.
