# 지도 우선 탐색과 이동수단 전환 기록

> 상태: 지도 우선 탐색과 도보·대중교통 자동 혼합 경로 적용 완료. 차량의 자동 조합은 택시·자차 정책 분리 뒤 추가한다.
>
> 기준일: 2026-08-15

## 1. 변경 전

사용자는 시간 설정 화면에서 `도보`, `대중교통`, `차량` 중 하나를 먼저 고른 뒤 후보 목록을 받았다. 이후 코스의 모든 구간은 선택한 한 가지 이동수단으로 계산했다.

이 방식은 계산이 단순하지만 다음 문제가 있었다.

- 장소를 보기 전에 이동수단을 고정해야 한다.
- 서면 근처는 도보로 들르고 해운대 약속 장소까지는 대중교통으로 가는 현실적인 흐름을 표현하기 어렵다.
- 한 수단 기준으로 후보를 줄여, 실제 선택지가 적어 보인다.

## 2. 변경 후 UX

1. 사용자는 현재 위치와 약속 장소·시각을 입력한다. 현재 위치는 GPS가 기본이며 직접 검색으로 바꿀 수 있다.
2. 후보 지도는 시간 안에 성립 가능한 장소를 한 번에 보여준다. 전역 이동수단 필터는 두지 않는다.
3. 마커 또는 후보 카드를 누르면, `출발 → 선택 장소 → 약속`을 아이콘 경로로 미리 보여준다. 핵심 지표는 `약속 전 여유`와 `이곳 체류 가능 시간` 두 개만 표시한다.
4. 기본 경로는 앱이 자동 제안하고 사용자는 바로 담을 수 있다. `직전 지점 → 선택 장소` 구간의 도보·대중교통·차량 아이콘을 누를 때만 해당 구간 수단을 바꾼다.
5. 선택한 수단은 해당 장소에 도착하는 구간에만 저장한다. 이후 구간은 자동 추천으로 시작하며, 장바구니 확정 전 실제 경로로 다시 검증한다.

예시:

```text
현재 위치  - 도보 8분 - 전포공구길 - 대중교통 27분 - 약속 장소
약속 전 여유 12분 | 이곳 체류 가능 65분
```

## 3. 변경 이유

- AIHub 체류시간은 평균 기준이므로, 빠듯한 장소를 처음부터 숨기면 사용자 선택권을 과도하게 제한한다.
- 약속 준수는 최우선으로 유지하되, 사용자가 체류시간 축소나 이동수단 변경을 판단할 근거를 제공한다.
- 관광 데이터로 검증한 장소를 지도에서 비교하게 해, 단순 근처 장소 목록이 아니라 시간 제약 기반 탐색 서비스라는 차별성을 유지한다.

## 4. 상태 정의

| 상태 | 의미 | 처리 |
| --- | --- | --- |
| 여유 있음 | 권장 체류시간과 안전 여유를 확보 | 미리보기에서 담기 가능 |
| 짧게 가능 | 권장 체류시간보다 짧지만 최소 체류는 가능 | 미리보기에서 담기 가능 |
| 빠듯함 | 최소 체류는 가능하나 여유가 작음 | 미리보기에서 담기 가능 |
| 시간 초과 | 최소 체류·안전 여유를 만족하지 못함 | 해당 조합으로 담기 차단 |

운영시간상 명확히 불가능하거나 데이터 정제에서 제외된 장소는 지도에 표시하지 않는다.

## 5. 현재 구현 범위와 후속 작업

현재 지도는 후보마다 세 수단의 근사 이동시간과 체류 가능 시간을 비교한다. 장소를 선택하면 앱은 현실적인 조합을 기본 제안하고, 사용자가 원할 때만 **그 장소까지 도착하는 구간**의 수단을 바꾼다. 선택하지 않은 구간은 가까우면 도보(약 14분 이내), 그 밖에는 대중교통으로 자동 조합한다. 장바구니 진입과 최종 확정 시에는 각 구간에 해당하는 TMAP 또는 ODsay 정밀 경로만 호출하고, 실제 이동시간으로 운영시간도 다시 검증한다.

확정 코스는 이미 `course_legs.mode`에 각 구간의 실제 수단을 저장하고, 진행 화면의 카카오맵 길찾기도 다음 구간의 수단을 사용한다.

```text
현재 위치 → 장소 1: 사용자가 선택한 도보
장소 1 → 장소 2: 도보
장소 2 → 약속 장소: 대중교통
```

- 차량은 택시와 자차를 분리한다. 택시는 구간별 사용을 허용하고, 자차는 차량 위치·주차 제약을 별도 정책으로 다룬다.
- 장소를 담을 때 선택 순서를 유지한다. 자동 순서 정렬은 장바구니에서 사용자가 명시적으로 실행할 때만 적용한다.
- 장소를 담거나 순서를 바꿀 때 바뀐 앞뒤 구간만 다시 계산하도록 호출 범위를 더 줄인다.

이동수단은 지도 전역 필터가 아니라 장소 미리보기의 구간 아이콘에서만 조정하며, 코스 전체 수단을 하나로 고정하지 않는다.
