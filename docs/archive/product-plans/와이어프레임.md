# TimeFit 와이어프레임 (텍스트) — v2 라이프사이클

> 작성: 2026-07-04 · 목적: 디자인 도구(Claude/Figma)에 넣어 화면을 생성하기 위한 **텍스트 와이어프레임**.
> 대상: iOS · 세로(portrait) · 다크 테마 · 모바일. 흐름 원본: `MVP시나리오.md` §1.
> 원칙: 폴리시 아닌 **레이아웃 + 데이터 + 화면 간 전달값**. 색은 아래 토큰.

## 1. 네비게이션 맵 (화면 전이 + 전달 데이터)

```
[입력] ──planTimeFit()──▶ [추천] ──코스 선택──▶ [상세]
  Home                     Results              Detail
                             ▲                    │ [이 코스로 갈래요]
                             │ (필터 재적용)        ▼
                             │              (로그인 유도 모달·선택)
                             │                    │
                             └───재추천────── [실행] ──코스 종료──▶ [피드백]
                            (시간 남으면)      Execution            Feedback
```

전달 데이터(네비 파라미터):
- 입력→추천: `{ result, remainingMin, usedTimeLabel, origin, appointment? }`
- 추천→상세: `{ course, origin, appointment? }`
- 상세→실행: `{ course, origin, appointment, departureSchedule[] }`
- 실행→피드백: `{ course, actualDurations? }`
- 피드백→입력/추천: (재추천 시) 줄어든 남은시간으로 재호출

## 2. 화면별 와이어프레임

### ① 입력 (Home) — 헤더 없음, 스크롤

```
┌──────────────────────────────┐
│  TimeFit               (로고) │  accent 34pt 800
│  붕 뜬 시간에 진짜 가능한 코스   │  muted 15pt
│                              │
│  다음 약속 (선택)              │  label
│  ┌────────────┐ ┌──────────┐ │
│  │ 🕒 15:00 ▾ │ │ 📍 장소   │ │  시각 피커 · 장소 입력
│  └────────────┘ └──────────┘ │  (미입력 시 아래 '남은시간' 사용)
│  └ 미입력 = 현재위치 왕복       │  muted 12pt
│                              │
│  남은 시간                    │  label (약속 미입력 시만 활성)
│  [30분][1시간][2시간][3시간][직접]│ 칩 row
│                              │
│  이동수단                     │
│  [🚶 도보] [🚌 대중교통] [🚗 차량]│  칩
│                              │
│  현재 위치                    │
│  [ 📍 현재 위치 사용 ]          │  버튼(panel)
│  부산 서면(기본)               │  muted
│                              │
│  🧪 테스트 시각 (개발용)        │  접이식
│  [실제 시각] [직접 설정]        │
│                              │
│  ┌──────────────────────────┐│
│  │   가능한 코스 찾기          ││  CTA green, 16pt 800
│  └──────────────────────────┘│
│  (에러 시 red 텍스트)          │
└──────────────────────────────┘
```
- **데이터-in:** GPS(expo-location), 현재시각
- **데이터-out → 추천:** `planTimeFit({origin, destination:약속장소|null, remainingMin, mode, nowMin, dayType, hourBucket})`
- **분기:** 약속 입력 시 remainingMin = 약속시각 − 현재시각 자동계산 / 미입력 시 칩 선택값
- **로그인 불필요** (게스트)

### ② 추천 (Results) — 헤더 "추천 코스", 스크롤

```
┌──────────────────────────────┐
│ ⏱ 주말 14:00·오후 · 후보 16 ·   │  meta muted 12pt
│   영업중 12 · 가용 105분         │
│                              │
│  분위기                       │  filter label
│  [자연][문화][도심]            │  칩(다중선택)
│  활동                         │
│  [먹기][보기][걷기][체험]       │  칩
│                              │
│  3개 코스                     │  count

│ │ 미니코스 2곳    총 100분 ›│   │  card: type green 800 / total txt2
│ │ ─────────────────────  │   │
│ │ 부산근대역사관            │   │  spot name 16 700
│ │ 관광지 · 체류 40분 · 🕒..│   │  meta muted
│ │ 광복로 거리              │   │

- **데이터-out → 상세:** 선택한 `course` + `origin` (+약속)

┌──────────────────────────────┐

│ │        [지도 300h]        │ │  Apple Maps

│ ┌────────────────────────┐   │
│ │ 1. 부산근대역사관         │   │  spot 카드
│ │ 관광지 · 체류 40분(POI실측)│   │

│ │ 2. 광복로 거리            │   │
│ └────────────────────────┘   │
│                              │

│ ┌────────────────────────┐   │
│ │ 출발→역사관  8분 [tmap]   │   │  leg

### ③.5 로그인 유도 (모달·선택) — 수락 직후

```
┌──────────────────────────────┐
│         (반투명 오버레이)       │
│  ┌────────────────────────┐  │
│  │ 알림을 받으려면 로그인      │  │
│  │ 코스 진행 중 "이동할 시간"   │  │
│  │ 알림과 기록을 위해 필요해요  │  │
│  │                        │  │
│  │ [ Apple로 계속 ]         │  │  주버튼
│  │ [ 나중에(게스트로 진행) ]  │  │  텍스트버튼 → 실행 그대로

└──────────────────────────────┘
```
- **스킵 가능** — 게스트로도 실행/알림(로컬)은 동작. 로그인은 기록·개인화용.

```

│ ┌──────────────────────────┐ │

│ └──────────────────────────┘ │
│ 약속까지 1시간 52분 남음         │  amber 강조
│                              │
│ 진행 타임라인                  │
│ ┌────────────────────────┐   │
│ │ ● 지금  부산역 출발        │   │  현재 단계 accent
│ │ │  🚶 8분                │   │
│ │ ○ 14:08 역사관 도착·체류40│   │
│ │ │  🚶 6분                │   │
│ │ ○ 14:54 광복로 체류30     │   │
│ │ │  🚶 10분               │   │
│ │ ◎ 15:10 약속장소 도착      │   │  종점 green

│                              │

- **데이터-out → 피드백:** `course` (+선택 실제소요)

│  역사관  [30][40][60][90]분    │  칩
│  광복로  [20][30][45]분        │
│                              │
│  또 가고 싶나요?  [예][아니오]   │
│                              │
│  ┌──────────────────────────┐ │
│  │   완료                    │ │  CTA
│  └──────────────────────────┘ │
│                              │

- **재추천 루프:** 남은시간 > 임계값이면 planTimeFit 재호출 → 추천으로

## 4. 디자인 도구 사용 힌트
- 각 화면을 위 ASCII 블록 단위로 프레임 생성 요청.
- 다크 테마(bg `#0f1419`), 카드 radius 12, 칩 라운드, 하단 CTA green(`#2ea043`).
- iPhone 세로(390×844 기준), 상단 세이프에어리어 고려.
- 컴포넌트 재사용: `칩(Chip)`, `코스카드`, `장소카드`, `구간(leg) 행`.
