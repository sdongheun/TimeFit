## 3. 결정 대기 항목

다음은 최근 논의로 방향이 바뀌었으나 아직 현행 기준 문서·코드·테스트에 함께 반영되지 않았다.

1. 최대 입력 시간: 기존 `2시간`에서 `3시간`으로 확대
2. 코스 단위: 기존 단일 장소에서 `1~3개 장소`로 재도입
3. 결과 표현: 대표 추천 코스 1개, `더보기` 지도에는 범위·시간 예산에 맞는 장소를 표시
4. 운영시간 미확인 시장·거리·골목: 대표 추천에서는 제외하고, 더보기에서는 `운영시간 확인 필요` 조건부 후보로 표시

위 항목은 [추천로직](03_product/추천로직.md)과 [테스트](테스트.md)의 기존 `단일 장소·2시간·미확인 지도 제외` 규칙과 충돌한다. 다음 구현 세션 전에 사용자 확정 기록을 추가하고, 그 뒤 관련 문서·테스트·코드를 같은 변경으로 갱신한다.

## 5. 세션 시작 체크리스트

1. 이 파일과 저장소 루트의 `AGENTS.md`를 읽는다.
2. 작업 대상의 기준 문서와 `docs/테스트.md` 요구사항 ID를 확인한다.
3. 결정 대기 항목과 충돌하면 구현을 시작하지 않고, 결정 트리에 기록할 질문으로 되돌린다.
4. 외부 API는 fixture·어댑터 경계로 검증하고, 실제 API 검증은 호출량을 기록한 소수 시나리오로 제한한다.
