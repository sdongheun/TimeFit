# 조건부 시장·거리 발견 후보 감사

기준일: 2026-08-31. 이 감사는 외부 API를 호출하지 않고, 현행 `conditional_more` 178개의 보존된 근거 프로필만 사용했다.

## 결과

| 판정 | 수 | 의미 |
| --- | ---: | --- |
| `conditional_visit` | 142 | 시장 134, 거리·골목 8. 정보 확인 영역에서만 표시 가능 |
| 제외 | 36 | 자동 대표·검증 대안·조건부 정보 확인 영역 모두에서 제외 |

적격 장소는 모두 다음 필드를 갖는다.

```json
{
  "kind": "market_or_street",
  "displayWindow": { "start": "10:00", "end": "18:00" },
  "requiresUserHoursConfirmation": true
}
```

`10:00–18:00`은 화면의 제품 탐색 창일 뿐 실제 영업시간·안전시간·공식 근거가 아니다. 카카오맵 확인 전에는 실제 시간표·`검증됨`·자동 추천을 만들 수 없으며, 명시 확인 뒤 계산이 성공해도 조건부 상태를 유지한다.

## 제외 근거

| 이유 | 수 | 예시 |
| --- | ---: | --- |
| 시설·개별 장소 등 권역 아님 | 20 | 부산 영화의 전당, 도서관 |
| 해변·공원·관광특구 등 시장/거리/골목 아님 | 6 | 다대포 해수욕장, 암남공원 |
| 도매·새벽·수산/유통 전문 | 6 | 충무동 새벽시장, 구포축산물도매시장 |
| 산책로 성격 | 2 | 송도 구름산책로, 오시리아 해안 산책로 |
| 예약·장기 이용 불확실 | 2 | 부전마켓타운, 감전시장 |

대표 190개와 `area_access` 2개에는 `conditionalVisit`을 부여하지 않았다. 기존 조건부 등급, 운영시간 원문, 체류 범위, 좌표, 사진, 원천 연결은 바꾸지 않았다.

세부 ID·포함/제외 이유는 [조건부_시장거리_발견후보_감사.json](../../data/processed/review/조건부_시장거리_발견후보_감사.json)에 보존한다.
