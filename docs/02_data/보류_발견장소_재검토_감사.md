# 보류 발견장소 재검토 감사

## 재검토 배경과 질문

기존 `hold` 중 공식 소개 원문만 없다는 이유로 활동 유형과 짧은 방문 적합성을 확정하지 못한 140개를 다시 판정했다. 질문은 관광지인지가 아니라, 20~60분 안에 완결되는 활동과 그 적용 범위·운영 가능성을 정직하게 기록할 수 있는지다.

## 대상과 결과

시작 큐 140개와 결과의 ID는 일대일로 일치한다. 보존된 부산시 공식 관광·쇼핑 원문을 우선 사용했고, 외부 조회는 하지 않았다.

| 결과 | 수 | 처리 |
| --- | ---: | --- |
| `representative_standard` | 24 | 공식 소개의 산책·전시·전망·소품 탐색 활동, 20/30/60(문화 120)분 AI-Hub 템플릿, 공식 시간 범위를 함께 기록 |
| `conditional_more` | 2 | 치유의 숲, 땅뫼산 황토숲길: 산책 활동은 명확하지만 운영 범위가 구조화되지 않아 더보기만 허용 |
| `hold` | 114 | 공식 원문 미보존, 넓은 장소의 진입점·짧은 구간 불명확, 예약·프로그램 의존, 대형 시설·상권, 시간 범위 불명확 |

대표 승격 예시는 색채마을·화명수목원·누리마루 APEC하우스·임시수도기념관·부산타워·국립부산과학관·벽화마을, 그리고 활동이 명확한 소품 탐색 시설이다. IKEA 동부산점·대형 상권·면세점·프로그램 의존 시설은 후보 수 보강을 이유로 승격하지 않았다.

## 근거와 범위

각 ID의 원문, 템플릿, 운영시간, 장소 범위, 판정 이유는 [결과 JSON](../../data/processed/review/보류_발견장소_재검토_결과.json)에 보존한다. `대표`로 바뀐 24개는 근거 프로필 생성 단계에서만 오버레이하며, 원천 없는 TourAPI 항목은 `hold`로 남겼다. 모든 승격은 2026-11-21 재검토 기한을 가지며, 만료일 이후에는 일반 근거 만료 게이트에 따라 다시 `hold`가 된다.

## 검증과 남은 경계

`node --test test/evidence-profile-classification.test.mjs`, `node --test test/busan-poi-catalog.test.mjs`, `npm run test:typecheck`, `git diff --check`를 통과했다. 외부 API·웹 호출은 0회다.

114개 `hold` 중 TourAPI 원문이 로컬에 남지 않은 장소와 넓은 자연·마을 권역은 공식 관리 주체에서 입구·짧은 구간·운영 범위를 확인하기 전까지 보류한다. 추천 정책, 엔진 시간식, UI, 외부 API 어댑터는 변경하지 않았다.
