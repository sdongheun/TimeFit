# 검토 JSON 안내

이 폴더는 장소 후보를 바로 앱에 넣기 전 검토한 결과를 둔다. `src/data/busan_poi_catalog.json`이 앱의 유일한 런타임 카탈로그다.

## 현재 유지

| 파일 | 역할 |
| --- | --- |
| `부산_자투리장소_카탈로그_초안.json` | 활성 후보와 `approved`·`conditional` 판정의 원천 |
| `부산_자투리장소_보류및제외.json` | 보류·제외 사유와 재검토 대상 |
| `사용중_장소_운영시간_원천감사.json` | TourAPI 실조회와 부산시 원천 운영시간 대조 |
| `현재사용_운영시간미확인장소.json` | 빈 운영시간 후보의 보조 추출 |
| `현재사용_중복장소후보.json` | 현재 카탈로그 중복 점검 |

## 재생성 가능한 주제별 감사

`권역형장소_*`, `부산시_공식관광장소_*`, `부산_문화시설_*`, `자연관광지_*`, `카카오_보조시설_*`, `새벽_*` 파일은 당시 정책을 검토한 감사 결과다. 앱이 직접 읽지 않으며, 파일명과 같은 `scripts/*.mjs`를 실행하면 재생성할 수 있다.

## 보관

`../archive/historical-reviews/`는 현재 재생성 파이프라인과 어떤 스크립트에서도 참조되지 않는 과거 검토 산출물이다. 삭제하지 않고 이름·내용을 보존한다.
