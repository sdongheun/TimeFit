# 검토 JSON 안내

이 폴더는 장소 후보를 바로 앱에 넣기 전 검토한 결과를 둔다. `src/data/busan_poi_catalog.json`이 앱의 유일한 런타임 카탈로그다.

## 전환 이력

2026-08-24에 이전 `approved / conditional` 상태를 근거 프로필 기반 `representative_core / representative_standard / conditional_more / hold`로 교체했다. 이전 상태는 활동 검토·하드 제외의 출발점으로 보존하며, 현행 런타임 생성에는 사용하지 않는다. 이유는 운영시간 미확인만 조건부로 남기고, 장소 동일성·활동·체류 근거 자체가 부족한 장소를 명시적으로 `hold`로 분리하기 위해서다. 상태: **현행**.

## 재생성 가능한 주제별 감사

`권역형장소_*`, `부산시_공식관광장소_*`, `부산_문화시설_*`, `자연관광지_*`, `카카오_보조시설_*`, `새벽_*` 파일은 당시 정책을 검토한 감사 결과다. 앱이 직접 읽지 않으며, 파일명과 같은 `scripts/*.mjs`를 실행하면 재생성할 수 있다.
