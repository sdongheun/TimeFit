# 짜투리(TimeFit)

부산에서 약속 또는 복귀 전 남은 시간에 들를 장소와 코스를 제안하는 iOS 우선 Expo 앱이다. 장소 데이터 근거, 시간·경로 계산의 신뢰성, 처음 사용하는 사람도 이해하는 화면 흐름을 함께 검증한다.

출시 앱은 iPhone용이며, 검색·지도 선택으로 지정한 부산 장소와 현재부터 최대 3시간을 바탕으로 추천한다. 검증된 한 장소를 먼저 제안하고 명시 선택으로 최대 두 장소 코스를 구성한다. 기기 GPS는 취득하지 않는다. 주변 둘러보기의 독립 길찾기, 앱/Live Activity 공유 진행, 방문 기록과 동의 기반 체류 개인화를 제공한다. [현재 기능·호출 구조](docs/03_product/현재기능과구조.md)에서 주 흐름과 과거 호환 코드를 구분한다.

## 시작하기

새 세션과 새 작업자는 다음 순서로 읽는다.

1. [`AGENTS.md`](AGENTS.md): 작업 원칙, 역할 경계, 테스트·기록 규칙
2. [`docs/README.md`](docs/README.md): 현재 기준 문서, 결정 대기 사항, 역할별 최소 읽기 범위
3. 맡은 역할의 기준 문서와 소유 경로

과거 정책과 구현 과정은 `docs/archive/`에 보관되어 있다. 현행 사양으로 해석하지 않는다.

## 현재 구조

```text
src/engine/   추천·시간·경로 계산과 외부 API 경계
src/data/     앱 번들용 정제 장소 카탈로그와 정책
src/ui/       Expo React Native 화면과 내비게이션
src/services/ API 어댑터·repository·인증·개인화 저장 연결
supabase/     SQL 마이그레이션·서버 함수
plugins/      Live Activity 네이티브 코드와 Expo 설정 플러그인
data/         원천·정제·검토 데이터
scripts/      데이터 빌드와 감사 스크립트
test/         단위·계약·UI 테스트
docs/         현행 기능 기준, 데이터 근거, 출시·변경 이력
```

## 검증

```bash
npm run test:typecheck
npm run test:ui
npm test
```

Metro는 작업자가 명시적으로 요청할 때만 실행한다. 실제 API 키와 사용자 데이터는 테스트 fixture나 커밋에 넣지 않는다.

## 작업 방식

역할별 소유 경계와 단일 작성자 파일은 [`AGENTS.md`](AGENTS.md)를 따른다. 하나의 세션은 하나의 역할만 맡고, 종료 시 `변경 파일 / 유지한 계약 / 테스트 결과 / 다음 결정`을 남긴다.
